# Reflection & Learning Plan

## A) Reflection

### What We Learned
In this project, we learned how to develop an object detection workflow on an embedded GPU device such as the NVIDIA Jetson Nano. We gained experience working with YOLO models, OpenCV, ONNX conversion, and understanding how GPU acceleration improves performance.

### What Went Well
The workflow setup and initial model testing went well. We were able to successfully run object detection using the YOLO model and organize the project structure on GitHub.

### Challenges Faced
One major challenge was setting up the Jetson environment and dealing with compatibility issues between Python, CUDA, and different libraries. Another challenge was understanding how to optimize the model using ONNX and TensorRT.

### Team Contribution
We worked collaboratively by dividing tasks such as environment setup, coding, debugging, and documentation. Each member contributed to building and testing the workflow.

---

## B) Learning Plan

### Knowledge Gaps
We identified gaps in our understanding of GPU optimization, TensorRT, ONNX workflows, and deploying AI models on embedded systems.

### Skills Needed for Scaling
To scale this project, we would need stronger knowledge in CUDA programming, real-time system design, and deep learning model optimization.

### Training and Resources
To improve our skills, we would use:
- NVIDIA Jetson documentation
- TensorRT tutorials
- Ultralytics YOLO documentation
- OpenCV resources
